# Frogs Cardano App (app + home-screen widgets)

Quick test (no install): paste App.js into snack.expo.dev (replace its App.js), open with Expo Go.

APK with home-screen widgets, built in the cloud (nothing to install on your computer):
1. Create a GitHub repo, upload everything here (incl. .github/workflows/build-apk.yml).
2. Actions > "Build Android APK" > Run workflow (10-15 min).
3. Download the artifact, install the APK on your phone.
4. Long-press home screen > Widgets > "Frogs Pool" (4x3) or "Frogs Blocks" (2x2).
5. To show a different pool: Explore > open a pool > "Use for widget", then tap the widget's refresh.
